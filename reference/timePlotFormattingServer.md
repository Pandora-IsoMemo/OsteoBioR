# Server function of time plot formatting

Backend for plot formatting module

## Usage

``` r
timePlotFormattingServer(id, savedModels)
```

## Arguments

- id:

  namespace id

- savedModels:

  list of models of class
  [`TemporalIso`](https://pandora-isomemo.github.io/OsteoBioR/reference/TemporalIso-class.md)
