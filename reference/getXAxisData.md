# Get X-Axis Data

Get X-Axis Data

## Usage

``` r
getXAxisData(object, oldXAxisData = data.frame())
```

## Arguments

- object:

  model of class
  [`TemporalIso`](https://pandora-isomemo.github.io/OsteoBioR/reference/TemporalIso-class.md)

- oldXAxisData:

  data.frame, output from previous run of this function
