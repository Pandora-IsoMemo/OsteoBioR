# Set Vars For Unc Matrix

Set Vars For Unc Matrix

## Usage

``` r
setVarsForUncMatrix(timeVars, indVar, renewalRates, renewalRatesUnc = NULL)
```

## Arguments

- timeVars:

  A character string specifying the name of the column indicating the
  time.

- indVar:

  (character) name of variable for individuals

- renewalRates:

  (matrix) matrix with renewal rates

- renewalRatesUnc:

  (matrix) matrix with renewal rates uncertainties
