# Paste Label for Derivation Plot

Get the labels for the x axis of the plot in case of showing the
derivation

## Usage

``` r
pasteLabelForDerivation(axesLabel, hidePastedLabels)
```

## Arguments

- axesLabel:

  (character) output of
  [`getLabel`](https://pandora-isomemo.github.io/OsteoBioR/reference/getLabel.md)

- hidePastedLabels:

  (logical) if TRUE then dont't show pasted labels
