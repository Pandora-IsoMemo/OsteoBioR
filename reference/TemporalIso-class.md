# S4 class for temporal estimation of isotopic values

Inherits from
[`stanfit`](https://mc-stan.org/rstan/reference/stanfit-class.html)

## Slots

- `regressor`:

  regressor used for estimation (class matrix)

- `time`:

  timestamps (class vector)

- `timeLower`:

  lower timestamps (class vector)

- `timeUpper`:

  upper timestamps (class vector)
