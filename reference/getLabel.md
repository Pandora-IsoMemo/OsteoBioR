# Get Label

Get Label

## Usage

``` r
getLabel(xAxisData, deriv, hidePastedLabels = TRUE)
```

## Arguments

- xAxisData:

  data.frame of time data of object, output of getXAxisData

- deriv:

  character "1" for absolute values, "2" for first differences

- hidePastedLabels:

  (logical) if TRUE then dont't show pasted labels
