# Extract Plot Data

Extract Plot Data

## Usage

``` r
updateTime(plotData, object, deriv = "1")
```

## Arguments

- plotData:

  (data.frame) plot data

- object:

  model of class
  [`TemporalIso`](https://pandora-isomemo.github.io/OsteoBioR/reference/TemporalIso-class.md)

- deriv:

  character "1" for absolute values, "2" for first differences
